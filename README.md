# キメラヘアマスター (Chimera Hair Master)

VRChat向けキメラヘア作成支援ツールです。複数の髪メッシュを統一感のある1つのヘアスタイルにまとめることができます。

## 目的

VRChatアバターのキメラヘア（複数の髪アセットを組み合わせたヘアスタイル）を作成する際に発生する以下の問題を解決します。

- 髪ごとに色味やテクスチャのトーンが異なる
- 複数のメッシュ・マテリアルが残りパフォーマンスが悪い
- マテリアル設定（質感・光沢など）がバラバラで統一感がない
- 異なる髪を組み合わせた時の位置・形状のズレ

## 機能一覧

### 色合わせ（カラーマッチング）

複数の髪テクスチャの色味を統一します。2つのモードを搭載しています。

- **色相シフトモード**: 元のシェーディングやコントラストを維持しながら色相だけを変更します。髪の陰影ディテールを残したい場合に最適です。
- **グラデーションモード**: 元の明暗をグラデーションカーブに沿って完全に置き換えます。色のパレットをゼロから設計したい場合に便利です。

さらに、以下の調整が可能です。

- 彩度・明度の保持度合いの調整
- 明るさ統一モード（最も明るいテクスチャ / 最も暗いテクスチャに合わせる）
- レンダラーごとの個別明るさ微調整

### メッシュ統合

複数の髪メッシュを1つのメッシュにまとめます。

- テクスチャアトラスの自動生成（512〜4096px対応）
- UVアイランド単位での配置調整
- ボーンの統合とリバインド
- レンダラー/サブメッシュ単位での統合対象選択

### マテリアル設定統一

ベースマテリアルを基準に、統合後のマテリアル設定を統一します。

- lilToonシェーダー対応
- MatCapテクスチャの統一
- プローブアンカー・バウンズの設定

### メッシュ変形

髪メッシュの形状を直接編集して位置や形のズレを修正できます。キメラヘアマスターのInspectorから使用できるほか、単体でも使用可能です。

#### 編集モード

- **パーツ変形**: UVアイランド（パーツ）単位でまとめて移動・回転・スケール
- **頂点変形**: 頂点を選択してギズモで細かく調整。影響範囲と距離減衰を設定可能
- **全体の形を調整（ラティス変形）**: メッシュを囲む格子の制御点を動かして、全体のシルエットを大まかに変形

#### 対称編集

- X（左右）/ Y（前後）/ Z（上下）軸での対称変形に対応
- 対称面の位置はScene上のハンドルまたはInspectorのオフセット値で調整可能
- 頂点変形・ラティス変形の両モードで使用可能

#### 頂点ツール

- **膨張/収縮**: 選択頂点を法線方向に膨らませたり縮めたりできます
- **スムージング**: 選択頂点の位置を滑らかにします

#### エクスポート

- 変形済みメッシュをアセットとして保存
- メッシュを保存して元のレンダラーに入れ替え（変形データをメッシュに焼き込み）

### メッシュ変形（単体利用）

キメラヘアマスターの色合わせ・メッシュ統合を使わず、メッシュ変形機能だけを独立して使用できます。

#### セットアップ方法

以下のいずれかの方法で追加できます。

- **メニューから**: 「キメラヘアマスター > メッシュ変形」でウィンドウを開き、Rendererを登録してセットアップ
- **Hierarchyから**: GameObjectを右クリック →「CHM - メッシュ変形を追加」

セットアップ後はInspectorから編集できます。編集モードや頂点ツールはキメラヘアマスターのメッシュ変形と同一です。

## 動作環境

- Unity 2022.3 以降
- [NDMF](https://github.com/bdunderscore/ndmf) 1.7.0 以降
- [lilToon](https://lilxyzw.github.io/lilToon/)（色合わせ・マテリアル統一機能で使用）

## 使い方

### キメラヘア作成

1. 「キメラヘアマスター > ウィンドウを開く」からウィンドウを開く
2. 統合したい髪のレンダラーを登録
3. セットアップ実行を押す
4. カラーモードを選び、目標の色を設定
5. 必要に応じてメッシュ変形で位置・形状を調整
6. プレビューで確認しながら調整
7. アバターをアップロード（NDMFが自動で処理）

### メッシュ変形のみ使用

1. Hierarchyで髪のGameObjectを右クリック →「CHM - メッシュ変形を追加」
2. Inspectorから編集モードを選んで変形
3. アバターをアップロード（NDMFが自動で処理）
